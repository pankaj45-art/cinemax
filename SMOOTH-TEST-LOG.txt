========== Additional timing and limitations ==========
Older Clean Impact fast-kick baseline: one original + limiter run had a -160-sample
source-correlation offset change; two further runs in each mode had none.
Earlier independent -66/-595 sample observations are in LOOPBACK-CONTINUITY.json.
One earlier synthetic WAV/MP3/M4A trial per mode found no detected offset jumps in
the captured portions; some original captures were considerably shorter than wall
time. These codec runs used a pre-selector 100 ms candidate, not the final page.

The optimized AudioWorklet core profile used 1 ms Date.now timing over 2,000
warm blocks per mode on this Linux host: mean 0.0655 ms enhanced, 0.068 ms original;
one original block registered 7 ms, against a nominal 2.902 ms block interval.
This does not establish real-time performance on Windows or that all deadlines
were met. See SMOOTH-PLAYBACK-MEASUREMENTS.json for timing and test data.
The virtual monitor, browser, host and clock can affect these recordings. None
is a physical listening test, a guarantee of inaudible artifacts, or a certified
true-peak measurement. The Windows batch launcher was not executed on Windows.
